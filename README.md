# 하루 (Haru)

일정, 할 일, 일기와 AI 비서를 한곳에서 사용하는 iPhone 앱입니다. Swift와 SwiftUI로 만들었습니다.

처음 코드를 받아 실행하는 분은 **[시작 안내](docs/SETUP_GUIDE.md)**부터 보세요. Xcode에서 프로젝트를 여는 방법, 위젯 설정, AI 키 입력 방법을 쉬운 순서로 설명합니다.

## 앱에서 할 수 있는 일

- **오늘**: 오늘 일정과 할 일을 확인하고, 체크박스로 완료 표시
- **캘린더**: 날짜별 일정 추가와 알림 설정
- **AI 비서**: 글이나 음성으로 일정·할 일을 제안받고 확인 후 추가
- **일기장**: 날짜, 날씨, 사진과 함께 기록
- **위젯**: 홈 화면과 잠금 화면에서 오늘의 일정·할 일을 확인
- **화면 설정**: 화면을 좌우로 넘기거나 아래 메뉴를 눌러 이동하고, 설정에서 사진 배경 선택

앱 화면은 한국어를 기본으로 합니다. 언어 설정은 날짜 표시 형식에 적용되며, 모든 화면 문구를 번역하는 기능은 아직 제공하지 않습니다.

## 처음 실행하기

1. Mac에 Xcode를 설치합니다.
2. 이 저장소를 내려받고 `haru2.xcodeproj`를 두 번 눌러 엽니다.
3. 위쪽 실행 대상에서 `haru2`와 iPhone 시뮬레이터를 선택합니다.
4. ▶ 버튼을 누릅니다.

자세한 그림 없는 단계별 안내와 실제 iPhone에서 실행하는 방법은 [시작 안내](docs/SETUP_GUIDE.md)에 있습니다. 프로젝트의 현재 최소 실행 버전은 iOS 26.5입니다.

## 파일을 찾을 때

- `Haru/Views/`: 앱에서 직접 보는 화면
- `Haru/Models/`: 일정·할 일·일기 정보의 모양
- `Haru/Services/`: 로그인, 알림, AI 연결처럼 화면 뒤에서 하는 일
- `Haru/Shared/`: 앱과 위젯이 함께 사용하는 데이터
- `HaruWidget/`: 홈 화면·잠금 화면 위젯
- `docs/PROJECT_GUIDE.md`: 각 폴더와 주요 파일을 초보자용 말로 설명

## 꼭 알아둘 점

- 일정, 할 일, 일기와 로그인 정보는 현재 기기 안에 저장됩니다. 여러 기기 간 동기화 서버는 연결되어 있지 않습니다.
- 위젯은 앱과 같은 데이터를 읽도록 Xcode에서 App Groups를 설정해야 합니다.
- AI 기능은 사용자의 동의를 받은 뒤 요청을 보냅니다. 키 없이도 앱은 실행되지만, AI를 사용하려면 [안내에 따라](docs/SETUP_GUIDE.md#ai-비서-설정-선택) 로컬 Xcode 실행 환경에 Gemini 키를 넣어야 합니다.
- API 키는 코드, 공유 Scheme, GitHub에 올리지 않습니다. 앱스토어 배포에는 앱 안에 키를 넣지 말고 별도 서버를 사용해야 합니다.
