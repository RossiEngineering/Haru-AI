# Haru 초기 기획 회의록

## 회의 목적

Haru를 "오늘 해야 할 일을 쉽게 기록하고, AI에게 말하면 알아서 정리해 주는 개인용 하루 관리 앱"으로 만든다.

## 핵심 결정

### 첫 화면
앱을 열면 가장 먼저 **오늘**을 보여준다.
- 오늘 일정
- 오늘 할 일
- 필요한 경우 AI가 정리한 내용

### 하단 메뉴
1. 오늘
2. 캘린더
3. AI 비서
4. 일기장

### AI 비서
글자와 음성을 모두 지원한다.

예:
> 내일 오후 3시에 치과 예약 있어

AI가 내용을 이해하고 일정 생성에 필요한 지시서를 만든다.

### 음성
iPhone 음성 인식으로 말을 텍스트로 바꾼 뒤 글자 입력과 같은 AI 흐름으로 보낸다.

### 위젯
홈 화면과 잠금 화면에서 오늘 해야 할 일을 확인한다.

앱이 오늘 요약을 공용 공간(App Group)에 저장하고 위젯이 읽는 구조를 사용한다.

### 로그인
초기 개발에서는 서버 없이 기기 안에서 로그인/회원가입을 구현한다.

### AI 모델
처음에는 Claude API를 고려했지만 개발 과정에서 **Google Gemini**로 변경했다.

### 보안
개발 단계에서는 API 키를 로컬 `Secrets.swift`에만 넣고 GitHub에는 올리지 않는다.

앱스토어 배포 전에는 API 키를 서버에서 보호하는 방식으로 변경한다.

### 개발 원칙
- 파일마다 "이 파일은 무엇을 하나요?" 설명을 둔다.
- 기능별로 파일을 나눈다.
- 오류가 생기면 원인과 해결 방법을 기록한다.
- 중요한 변경마다 Git 커밋을 남긴다.
