실제 API 키를 Swift 소스 파일에 붙여 넣지 마세요.

AI 기능을 시험하려면 Xcode에서 아래처럼 설정합니다.
1. Product > Scheme > Edit Scheme을 엽니다.
2. 왼쪽에서 Run을 선택하고 Arguments 탭을 엽니다.
3. Environment Variables에서 + 를 누릅니다.
4. Name에 GEMINI_API_KEY, Value에 본인의 Gemini API 키를 입력합니다.
5. Run 구성(Debug)에서만 설정하고, 공유 Scheme이나 GitHub에는 키를 저장하지 않습니다.

AI 기능을 사용하지 않을 때는 이 값을 비워 둬도 앱을 빌드하고 실행할 수 있습니다.
앱스토어 배포에서는 앱 안에 키를 넣지 말고, 서버를 통해 AI를 호출하도록 설정하세요.
